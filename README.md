# Análise de Acidentes de Trânsito no Brasil

   ## Sobre o projeto:
Este projeto tem como objetivo praticar SQL e analisar dados de acidentes de trânsito no Brasil utilizando PostgreSQL.


   ## Ferramentas utilizadas:

PostgreSQL
pgAdmin 4
SQL
GitHub


   ## Análises realizadas:

Visualização e contagem de registros;
Análise de acidentes por estado;
Identificação das causas mais frequentes;
Análise de acidentes por município;
Análise de acidentes por mês;
Consultas relacionadas às vítimas dos acidentes.


   ## Objetivo de aprendizagem:

Desenvolver habilidades em consultas SQL, agrupamento de dados, funções de agregação, filtros e ordenação.


## Fonte dos dados:
Dados públicos de acidentes de trânsito da Polícia Rodoviária Federal (PRF).


## Observação: as análises e os resultados serão documentados conforme as consultas forem executadas e validadas.
